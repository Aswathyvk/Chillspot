# 🎯 ChillSpot CUCEK – Campus Companion Platform  

## 📌 Overview  
ChillSpot CUCEK is a web-based campus companion application designed for students of Cochin University College of Engineering Kuttanad (CUCEK). It provides a centralized platform that connects academic resources, campus facilities, and recreational features to enhance student experience.
